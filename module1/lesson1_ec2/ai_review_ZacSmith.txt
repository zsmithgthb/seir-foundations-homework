QUESTION 4 - HOW CAN I VERIFY COBOL RETURN CODES?

Question: How do I deliberately trigger return codes 0, 4, 8, and 12?

AI answer in my own words: COBOL applications use exit codes to indicate outcomes. In the Linux shell, echo $? immediately after the program shows that program's exit status. The four homework cases are success, account not found, business rejection, and environment/file access failure.

How I checked it: All these tests were performed on Run 7, instance i-099a4999305700832.

Code 0: I ran ./cobol/bin/account_lookup 100001 followed by echo $?. Alice Johnson's active account was returned, with BALANCE=5000.00; the exit status was 0. Proof: screenshots/cobol_rc0.jpg.

Code 4: I ran ./cobol/bin/account_lookup 999999 followed by echo $?. The output included ERROR=ACCOUNT NOT FOUND and ACCOUNT=999999; the exit status was 4. Proof: screenshots/cobol_rc4.jpg.

Code 8: I ran ./cobol/bin/payment_post TXN-ZS-0004 100001 0.00 USD INV-1004 followed by echo $?. The output included STATUS=REJECTED and REASON=AMOUNT MUST BE GREATER THAN ZERO; the exit status was 8. Proof: screenshots/cobol_rc8.jpg.

Code 12: From /tmp, I ran /opt/balerica-bank/cobol/bin/account_lookup 100001 followed by echo $?. The output included ERROR=CANNOT OPEN data/accounts.dat and FILE-STATUS=35; the exit status was 12. Proof: screenshots/cobol_rc12.jpg.

What I learned: The program's current directory can affect relative file paths, and not every nonzero exit code means the entire installation failed.
