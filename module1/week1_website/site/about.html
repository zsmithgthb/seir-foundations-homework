About This Project

This website demonstrates how cloud infrastructure can host a functioning web application.

Amazon EC2

Amazon Elastic Compute Cloud provides the virtual server that runs this website in the AWS Ohio region.

Apache and Amazon Linux

Amazon Linux 2023 is the server operating system. Apache handles incoming HTTP requests and serves the website.

HTML, CSS, and JavaScript

HTML provides the three-page structure, CSS controls the presentation, and JavaScript powers the calculator.

Automation with User Data

A Bash startup script installs Apache, creates the website files, and starts the web server automatically.
